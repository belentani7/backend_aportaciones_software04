# Activos

Guarde aquí únicamente recursos aprobados para el proyecto, como iconos propios, ejemplos anonimizados o imágenes de referencia con derechos de uso confirmados.

No añada credenciales, datos personales, imágenes de personas reales sin autorización o salidas que no deban compartirse en el repositorio. Los medios generados para publicación deben mantenerse en almacenamiento privado hasta completar la revisión humana.
