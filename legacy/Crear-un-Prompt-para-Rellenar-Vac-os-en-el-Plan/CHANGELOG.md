# Changelog

## 1.0.0 — 2026-08-28

- Reemplazado el scaffold de ejemplo por un dashboard operativo en español.
- Añadidas tablas de negocios, campañas, leads, consentimiento, mensajes, citas y auditoría.
- Añadida importación CSV con preview, deduplicación y errores por fila.
- Añadida suppression list, revocación y endpoint público de unsubscribe.
- Añadido motor de dry-run con plantillas y variables cerradas.
- Añadidos rate limit básico y health/readiness checks.
- Añadidos tests de política de consentimiento y templates.
- Documentados arquitectura, seguridad, API, base de datos, despliegue, testing y operación.
- No se activan todavía proveedores de email/WhatsApp ni envíos live por falta de credenciales y aprobación de negocio.
