# saas-plasma-extracted

SaaS Plasma - base de aplicacion Next.js.

## Requisitos
- Node.js 20+

## Instalacion
```bash
git clone https://github.com/belentani7/saas-plasma-extracted.git
cd saas-plasma-extracted
pnpm install
```

## Uso
```bash
npm run dev
```
