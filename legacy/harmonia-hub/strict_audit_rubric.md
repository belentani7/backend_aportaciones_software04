# Rúbrica de Auditoría Extrema — Estándar Implacable 10/10

Para obtener un 10/10 inquebrantable en cada una de las seis dimensiones requeridas, no se tolerará ningún tipo de simulación, hueco tipado, advertencia en compilación, fallo en tests o interfaz incompleta.

1. **Backend (10/10):** Tipado estricto extremo en tRPC/Express, cero errores en Drizzle/MySQL, manejo formal de errores con códigos HTTP exactos, autenticación basada en cookies HttpOnly/Secure/SameSite con rotación, y cero fugas de memoria o timeouts en workers.
2. **Frontend (10/10):** React 19 optimizado, Tailwind v4 / NativeWind con glassmorphism real (`backdrop-filter: blur(16px)`), paleta monocromática estricta con acentos púrpuras, accesibilidad WCAG y transiciones fluidas sin parpadeos.
3. **Utilidad (10/10):** Funcionalidad probada para flujos reales (captura inteligente, CRM autónomo, automatización persistente), con cero dependencia de servicios externos costosos (costo anual < 12 €).
4. **Relevancia (10/10):** Arquitectura local-first soberana, defensa activa contra inyecciones de prompts en contenido web, y adaptabilidad total a flujos de trabajo con IA autónoma.
5. **Potencial (10/10):** Modelo de ingresos claro (SaaS / Open Source con valor empresarial), arquitectura horizontalmente escalable, y diseño listo para contenedores y despliegue rápido.
6. **Identidad (10/10):** Coherencia absoluta de marca, nombre único (HARMONÍA / BELENTANI), documentación técnica impecable y cumplimiento normativo estricto.

*Condición inquebrantable:* Si alguna de las seis dimensiones no alcanza exactamente 10.0 sobre 10, **la publicación en GitHub se bloquea de inmediato**.
